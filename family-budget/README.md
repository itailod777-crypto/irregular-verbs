# תקציב המשפחה

ניהול הוצאות והכנסות משפחתי. **רץ רק על המחשב שלך**: השרת מאזין על `127.0.0.1` בלבד, בלי שירותי ענן ובלי טלמטריה.
העסקאות נמשכות אוטומטית מהבנקים וחברות האשראי הישראליות (ספריית [israeli-bank-scrapers](https://github.com/eshaham/israeli-bank-scrapers)), מסווגות לקטגוריות, ובסוף החודש מתקבל סיכום.

## מה יש בפנים
- **דשבורד** (בית): הכנסות, הוצאות, יתרה, מגמה של 6 חודשים, פילוח לקטגוריות, תקציב עם פסי התקדמות וסיכום סוף חודש להדפסה / PDF.
- **הוצאות חוזרות** (מנויים, חשבונות, ארנונה...) ו**הוצאות חד-פעמיות** בעמודים נפרדים. זיהוי אוטומטי, עם אפשרות לתקן.
- **עסקאות**: חיפוש וסינון, תיקון קטגוריה (המערכת מציעה ליצור חוק ולהחיל אותו על עסקאות דומות), הוספה ידנית (מזומן).
- **קטגוריות וחוקים** שאפשר להוסיף ולערוך, ו**תקציב חודשי** לכל קטגוריה.
- **יבוא קובץ** CSV / xlsx עם זיהוי עמודות בעברית (כולל קידוד windows-1255 ישן).
- **מניעת כפילויות**: hash של תאריך+סכום+שם בית עסק, כך שאפשר למשוך ולייבא שוב ושוב.
- **יומן משיכות**, באנר כשל בדשבורד, והתראה אופציונלית ב-[ntfy.sh](https://ntfy.sh).

## התקנה

דרישות: Node.js 22.13 ומעלה.

```bash
npm install
npm start
```
ואז לפתוח http://127.0.0.1:3000. אפשר גם ללחוץ פעמיים על `start.bat` (Windows) או `start.command` (Mac) / `start.sh` (Linux).

> `npm install` מוריד גם דפדפן Chromium (כמה מאות MB) שהספרייה משתמשת בו כדי להיכנס לאתרי הבנקים. הפרטים נשלחים רק לאתרי הבנק עצמם.

### הכי נוח ב-Windows: קיצור דרך עם לוגו
לחיצה כפולה פעם אחת על `install-windows.bat`. הוא יוצר על שולחן העבודה אייקון **Family Budget** שפותח את האפליקציה בחלון משלה (בלי שורת דפדפן ובלי חלון שחור), והשרת עולה ברקע אוטומטית עם Windows, כך שהמשיכה היומית רצה לבד. להסרה: מחק את שני הקיצורים (שולחן העבודה ותיקיית ההפעלה `shell:startup`). לוג השרת ב-`data\server.log`.

### התקנה שמתעדכנת בלחיצה (Windows, עם Git)
התקן [Git](https://git-scm.com), ולחץ פעמיים על `setup-from-git.bat` (או הרץ `git clone -b claude/adoring-planck-5kbmev https://github.com/itailod777-crypto/irregular-verbs.git`). הוא מוריד ל-`%USERPROFILE%\FamilyBudget` ומפעיל את `install-windows.bat`. מאותו רגע, כל עדכון הוא לחיצה כפולה על `update.bat`: מוריד את הגרסה החדשה, מתקין תלויות ומפעיל מחדש. תיקיית `data` (הנתונים והכספת) לא נוגעים בה. כל מחשב מתעדכן בנפרד, והנתונים לא משותפים בין מחשבים. להעברת נתונים למחשב אחר מעתיקים את `data` (ונדרשת סיסמת-העל).

### התקנה כאפליקציה במחשב (בלי קוד)
1. **מהדפדפן (הכי פשוט):** פתח את הכתובת ב-Chrome/Edge ולחץ על סמל ההתקנה בשורת הכתובת ("התקן את תקציב המשפחה"). האפליקציה תקבל לוגו, חלון משלה וקיצור דרך. השרת צריך לרוץ ברקע (`start.bat`).
2. **תוכנת שולחן עבודה עצמאית (Electron):** מתקין עם לוגו, אייקון במגש המערכת, הפעלה אוטומטית עם המחשב, והשרת עולה לבד עם האפליקציה. בונים פעם אחת על המחשב שלך:
   ```bash
   npm install
   npm run dist      # יוצר מתקין בתיקיית dist: exe ל-Windows, dmg ל-Mac, AppImage ל-Linux
   npm run desktop   # או: הרצה ישירה בלי מתקין
   ```
   באפליקציה הזו אפשר לסמן "זכור במחשב הזה": סיסמת-העל נשמרת מוצפנת בעזרת מחזיק המפתחות של מערכת ההפעלה, והכספת נפתחת לבד (חיוני למשיכה יומית ברקע). סגירת החלון שולחת אותה למגש, ו"יציאה" בתפריט המגש סוגרת אותה לגמרי.
   הנתונים נשמרים בתיקיית המשתמש של המערכת. לצורך המשיכה מהבנקים יש להתקין פעם אחת דפדפן: `npx puppeteer browsers install chrome`.

## חיבור חשבון
1. נכנסים ל"חשבונות ומשיכות", יוצרים **כספת** ובוחרים **סיסמת-על** (8 תווים לפחות). אין דרך לשחזר אותה.
2. מוסיפים בנק או כרטיס אשראי ומזינים את פרטי הכניסה **בממשק או בטרמינל** (`npm run set-credentials`, קלט מוסתר). הפרטים לא נשלחים לאף מקום חוץ מאתר הבנק.
3. לוחצים "משוך עכשיו". מכאן והלאה זה מתעדכן לבד. עד שמוסיפים חשבון המערכת ריקה, ועם הצטרפות הנתונים כל הרישום והסיווג מתחילים אוטומטית.

לבדיקה בלי חשבון אמיתי: `npm run demo` (נתוני דוגמה מזויפים במסד נפרד `data-demo/`).

## אבטחה
- השרת מאזין רק על `127.0.0.1`, עם הגנה מפני DNS-rebinding ו-CSRF מאתרים אחרים (בדיקת Host/Origin וכותרת בקשה) ו-CSP קשיח.
- **לא נשמרים מספרי כרטיס אשראי**, רק פרטי כניסה לאתרים.
- פרטי הכניסה בקובץ `data/vault.json` מוצפנים ב-AES-256-GCM, המפתח נגזר מסיסמת-העל באמצעות scrypt. אין טקסט גלוי בשום קובץ. סיסמאות לא נכתבות ללוגים (גם הודעות שגיאה מנוקות).
- קריאה בלבד: הספרייה רק נכנסת וקוראת עסקאות; אין שום פעולה פיננסית.
- `data/` מחוץ ל-git, בהרשאות 700/600 (ב-Windows ההרשאות נקבעות לפי חשבון המשתמש).
- ההתראה ב-ntfy.sh (אם הוגדרה) כוללת הודעה כללית על כשל, בלי סכומים. בלי נושא מוגדר, שום בקשה לא יוצאת לאינטרנט.

## משיכה יומית אוטומטית
האפליקציה (בשרת או בגרסת שולחן העבודה) מושכת פעם ביום מהשעה שהוגדרה בהגדרות, כל עוד היא פתוחה והכספת פתוחה. להרצה עצמאית בלי שהאפליקציה פתוחה, `npm run sync` מושך מכל החשבונות ויוצא עם קוד 1 בכשל.
הסיסמה נלקחת מ: `BUDGET_KEY_FILE` או `data/master.key` (קובץ בהרשאות 600 שמכיל את סיסמת-העל) או `BUDGET_MASTER_PASSWORD`.
**פשרה אבטחתית:** קובץ המפתח מאפשר אוטומציה, אבל מי שיש לו גישה לקובץ ולכספת יכול לפענח אותם. שמור על המחשב נעול ומוצפן (BitLocker / FileVault). בגרסת שולחן העבודה "זכור במחשב הזה" הוא חלופה טובה יותר.

- **Windows (Task Scheduler):** `schtasks /Create /SC DAILY /ST 06:30 /TN "FamilyBudgetSync" /TR "cmd /c cd /d C:\path\family-budget && node scripts\sync.js"`
- **Mac (launchd):** קובץ `~/Library/LaunchAgents/local.familybudget.sync.plist` עם `ProgramArguments` = `node`, `/path/family-budget/scripts/sync.js`, ו-`StartCalendarInterval` (Hour=6, Minute=30). לטעון עם `launchctl load`.
- **Linux (cron):** `30 6 * * * cd /path/family-budget && /usr/bin/node scripts/sync.js >> data/sync.log 2>&1`

## גיבוי
`npm run backup [תיקייה]` יוצר עותק עקבי של המסד והכספת (הכספת נשארת מוצפנת). אפשר גם להעתיק את כל תיקיית `data/`. גבה את סיסמת-העל בנפרד (למשל במנהל סיסמאות). בלעדיה הכספת אינה ניתנת לשחזור.

**שים לב:** זיהוי הכפילויות מבוסס על תאריך, סכום ושם בית העסק. אם קובץ שיובא מציג את שם בית העסק אחרת ממה שהבנק מחזיר במשיכה, אותה עסקה עלולה להיספר פעמיים. לפני יבוא לתקופה שכבר נמשכה, בדוק במסך הבדיקה המקדימה שמספר ה"כפולות" סביר.

## כשהמשיכה נשברת
1. הבאנר האדום בדשבורד ו"יומן משיכות" מציגים את הסיבה (`INVALID_PASSWORD`, `CHANGE_PASSWORD`, `TIMEOUT`, `GENERIC`...).
2. **סיסמה / חשבון ננעל / החלפת סיסמה:** היכנס לאתר הבנק ידנית, פתור, ועדכן את הפרטים (`npm run set-credentials`, "עדכון").
3. **הבנק שינה את האתר:** עדכן את הספרייה: `npm update israeli-bank-scrapers`. אם עדיין נשבר, ייתכן שצריך לחכות לתיקון בספרייה.
4. **בינתיים:** הורד קובץ מהאתר ויבא אותו ב"יבוא קובץ". הכפילויות מסוננות, כך שאין סכנה.

## מגבלות
- **עסקאות שעדיין לא עודכנו** (ממתינות) אצל חברת האשראי מדולגות, כי הן עשויות להשתנות. הן ייכנסו במשיכה הבאה אחרי שהחיוב יתעדכן, ולכן הסכום החודשי עשוי להתעדכן לאחור.
- **מזומן** לא נראה בשום בנק: מוסיפים ידנית ("הוספה ידנית"). משיכת מזומן מהכספומט כן נרשמת, בקטגוריה "מזומן".
- **חשבונות שדורשים קוד SMS** (למשל וואן זירו, ובחלק מהמקרים בנקים אחרים) דורשים הכנסת הקוד פעם אחת בטרמינל (`npm run set-credentials`); לאחר מכן נשמר טוקן ארוך טווח. חשבון שמבקש קוד בכל כניסה לא יכול להימשך אוטומטית, ויש להסתמך על יבוא קובץ.
- חיוב כרטיס האשראי שמופיע בחשבון הבנק מסווג כ"תשלום כרטיס אשראי" ואינו נספר כהוצאה, כדי לא לספור פעמיים. אם מושכים רק את הבנק ולא את הכרטיס, חסרות הוצאות הכרטיס.
- הזיהוי של הוצאה חוזרת הוא הערכה (בית עסק שמופיע ב-3 מתוך 6 חודשים בסכום דומה, או קטגוריה חוזרת מטבעה). אפשר לתקן ידנית.
- קבצי `xls` ישנים לא נתמכים: שמור כ-xlsx או CSV.
- ספריית הסריקה נשענת על האתרים של הבנקים ועלולה להישבר כשהם משתנים. הבדיקות כאן רצות מול סורק מדומה, ולכן החיבור לבנק האמיתי שלך נבדק רק כשתריץ אותו.

## בדיקות
